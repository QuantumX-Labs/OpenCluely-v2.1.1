From source to first launch

Get up and running
in a few steps.

Use the repository setup script to install dependencies, prepare optional Whisper components and launch the app. Consult the README for current platform notes.

Clone the repository

Open a terminal and download the project.

git clone https://github.com/rudra00434/OpenCluely-v2.0.git
cd OpenCluely-v2.0

Run setup

Run the setup script from the project directory.

./setup.sh

Configure your AI key

On first launch, open Settings and add your Gemini API key, or configure it in your local .env file.

GEMINI_API_KEY=your_gemini_api_key

Windows

Use Git Bash (included with Git for Windows) to run the setup script.

  • Install Git for Windows and Node.js 18+.
  • Open Git Bash in the cloned folder.
  • Run ./setup.sh.

macOS & Linux

Use your terminal from the cloned project directory.

  • Install Git and Node.js 18+.
  • Run ./setup.sh.
  • Follow prompts for API and optional speech setup.
Keep API keys private. Do not commit your .env file. Voice is optional; Whisper and Azure Speech require their respective setup or credentials. macOS users should follow the source-run instructions in the README.

A few useful details

Frequently asked questions.

What is OpenCluely v2.0?

An open-source Electron desktop assistant customized with Markdown-driven multi-skill prompt support and AI-assisted voice, screenshot and chat workflows.

What changed in the v2.0 skill system?

Skill-specific instructions are organized as separate Markdown files in the prompts directory and loaded by the application.

Does this page's demo call a real AI model?

No. It is a front-end simulation illustrating skill selection. The desktop app uses its configured AI provider.

Do I need an API key?

The project README identifies a Gemini API key as the required AI provider credential. Keep it in local settings or your private environment file.

Is voice input mandatory?

No. Voice is optional. The README documents local Whisper and Azure Speech configuration options.

Where can I find installation help?

Use this guide and consult the repository README for current commands, platform notes and troubleshooting.

Use responsibly. OpenCluely is presented as a learning, coding-practice and technical-exploration companion.
