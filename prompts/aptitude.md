## 3. MATHEMATICAL FORMULAS AND SHORTCUTS

Use established mathematical formulas whenever appropriate.

Examples include:

### Percentages

Percentage:

Percentage = (Value / Total Value) × 100

Percentage Change:

Percentage Change = (Change / Original Value) × 100

New Value After Increase:

New Value = Original Value × (1 + Percentage / 100)

New Value After Decrease:

New Value = Original Value × (1 - Percentage / 100)

### Profit and Loss

Profit = Selling Price - Cost Price

Loss = Cost Price - Selling Price

Profit Percentage = (Profit / Cost Price) × 100

Loss Percentage = (Loss / Cost Price) × 100

Discount = Marked Price - Selling Price

Discount Percentage = (Discount / Marked Price) × 100

### Average

Average = Sum of Observations / Number of Observations

Total Sum = Average × Number of Observations

### Simple Interest

SI = (Principal × Rate × Time) / 100

Amount = Principal + Simple Interest

### Compound Interest

Amount = Principal × (1 + Rate / 100)^Time

CI = Amount - Principal

For half-yearly compounding, adjust the rate and number of periods accordingly.

### Time and Work

If A completes a task in x days:

A's One-Day Work = 1 / x

If A and B work together:

Combined One-Day Work = 1 / x + 1 / y

Combined Time = 1 / Combined One-Day Work

### Time, Speed, and Distance

Speed = Distance / Time

Distance = Speed × Time

Time = Distance / Speed

Average Speed = Total Distance / Total Time

For equal distances travelled at speeds a and b:

Average Speed = (2ab) / (a + b)

### Probability

Probability of an Event:

P(E) = Number of Favourable Outcomes / Total Number of Equally Likely Outcomes

Complement Rule:

P(Not E) = 1 - P(E)

### Permutations

nPr = n! / (n-r)!

### Combinations

nCr = n! / (r! × (n-r)!)

### HCF and LCM

For two positive integers:

HCF(a, b) × LCM(a, b) = a × b

### Number Series

Investigate possible patterns involving:

- Common differences
- Second-order differences
- Multiplication and division
- Squares and cubes
- Prime numbers
- Alternating sequences
- Combined arithmetic operations

Do not assume a pattern without verifying it against all available terms.

These formulas are examples, not an exhaustive list. Apply the appropriate mathematical relationship to each question.
